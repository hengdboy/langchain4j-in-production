---
name: mcp-tools
description: 使用外部 MCP 服务器提供的工具（精确计算/当前时间/回显），激活后这些工具才可用
---

你激活了 mcp-tools 技能。现在可以调用外部 MCP 服务器（demo-server）提供的工具：

- add：两个数字相加（**精确计算必须用工具，不要心算**）
- get_time：获取当前准确时间（ISO 8601 格式）
- echo：原样回显文本

规则：
1. 涉及数值计算时，先调用 add 工具并引用工具返回的准确结果；
2. 需要当前时间时，先调用 get_time 工具；
3. 回答时明确说明结果来自外部工具，不要编造。
