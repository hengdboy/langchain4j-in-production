产品常见问题 FAQ（客服知识库）
==============================

一、退换货政策
--------------
1. 支持 7 天无理由退货，商品需保持完好，不影响二次销售。
2. 商品存在质量问题的，消费者有权要求退款或换货，运费由商家承担。
3. 定制类商品（如刻字、定制尺寸）不支持无理由退货，请在下单前确认。
4. 退货请先联系客服获取退货单号，未获单号的包裹可能被拒收。

二、退款说明
------------
1. 退款将在审核通过后 3 个工作日内原路退回您的支付账户。
2. 使用优惠券的订单退款时，优惠券金额不予退还，仅退实际支付金额。
3. 部分退款场景：缺货商品可申请部分退款，不影响其他商品继续发货。
4. 退款审核一般在 24 小时内完成，节假日顺延。

三、支付方式
------------
1. 支持支付宝、微信支付、银行卡、花呗分期等多种支付方式。
2. 大额订单（单笔超过 1 万元）建议使用对公转账，可开具增值税专用发票。
3. 支付失败时请检查银行卡余额或额度，10 分钟内可重试，订单不会重复扣款。
4. 发票申请：订单完成后可在"我的订单-申请发票"中开具电子普通发票。

四、物流配送
------------
1. 默认使用顺丰速运，下单后 24 小时内发货。
2. 偏远地区（新疆、西藏等）发货时效延长 1-2 天，运费按实际收取。
3. 支持物流轨迹查询，可关注公众号绑定手机号实时推送。
4. 签收时请当面验货，发现破损请拍照拒收并联系客服处理。
